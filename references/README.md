# Earlier guides

These two Markdown documents are preserved as earlier editions and background material.

1. [Designing Efficient SIMD Loop Architectures — SSBM-focused guide](SIMD_Loop_Architecture_SSBM.md) explains the concepts in the [civcode/ssbm](https://github.com/civcode/ssbm) project. It is tied to that source code and its benchmark findings.
2. [Designing Efficient SIMD Loop Architectures — algorithm-agnostic guide](SIMD_Loop_Architecture_Algorithm_Agnostic.md) removes the implementation-specific subject matter and introduces the abstract P/O/R iteration-space vocabulary.

The **new handbook** is the maintained, expanded teaching resource: [start at its table of contents](../book/README.md). The reference guides are retained intact to preserve their original scope and provenance.

All examples in the new handbook are abstract pseudocode; no processor-specific intrinsic programming is required.
